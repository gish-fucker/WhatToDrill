Privacy

隐私政策

生效日期：2026 年 7 月 27 日

部署模式与默认处理

本应用采用本地优先设计。GitHub Pages 不提供同源账号或云同步；未完整配置 Supabase 的 Node/Render 部署也只使用本机模式。只有 Node/Render 正确配置 Supabase 后，已登录用户才能主动开启云备份。普通记录、部署应用或登录账号都不会自动上传数据。

当前浏览器处理的数据

日常状态、训练记录、动作库、模板、偏好、每周计划训练日及其生效历史、下一训练计划、建议历史和支持约定默认保存在当前浏览器的本地存储。浏览器还保存是否开启同步、账号 ID、revision、checksum、冲突和删除状态等同步 metadata。导入的 JSON 与 Strong/Hevy CSV 在当前浏览器校验和解析；导出的 JSON、CSV 或 Markdown 文件由你选择保存位置并自行管理。

本地 Beta 记录

本地 Beta 记录不是在线用户分析。它只在当前浏览器保存匿名本机 installationId、事件名、时间、应用和算法版本、模板或计划 ID，以及环境、目标和推荐反馈枚举；不保存备注、动作实际重量、次数、时长、RPE、疼痛原文、邮箱、Cookie 或身份令牌，不会上传健康内容。记录最多保留最近 1000 条，可在应用帮助页单独查看、清除和导出；它不进入普通 JSON 备份、普通导入、云备份或第三方分析平台。清空训练与设置数据不会同时清除本地 Beta 记录，须使用该区域的独立清除操作。

账号、服务器与 Supabase

提供账号服务时，邮箱、验证码、认证用户 ID 和令牌由 Supabase Auth 处理；Node 服务端代理同源请求，并以 HttpOnly、SameSite=Strict Cookie 保存会话，使页面脚本不能读取令牌。服务器验证请求、在内存中使用网络地址和用户 ID 限流，并把云备份请求转交 Supabase；应用服务器本身不把完整记录另存为持久副本。登录不会自动上传记录，也不表示已经订阅。部署者启用服务权益后，Supabase 还会保存用户 ID、随机请求 ID、云端建议配额事件及时间；这些配额事件不包含训练内容、健康状态或备注。

可选云备份

你主动开启后，浏览器会向同源 Node 服务发送包含日常状态、训练、动作、模板、偏好、下一训练计划、建议历史和支持约定的完整 JSON 快照。Supabase 数据库保存用户关联、schema 版本、revision、checksum、快照内容和更新时间，用于备份、冲突检测和多设备同步。传输使用部署站点的 HTTPS；快照不是只有用户持有密钥的端到端加密数据，部署者及其 Supabase 项目按权限可能处理这些内容。

本机、云端与账号删除

开启云备份、停止同步、退出账号、清空本机和删除云端备份是不同操作。停止同步保留本机和云端已有数据；退出账号保留两侧数据并结束当前会话；清空本机删除当前浏览器记录但不自动删除云端备份或认证账号；删除云端备份保留当前设备记录、停止同步，并把云端快照内容替换为用于其他设备识别删除的 tombstone。其他设备看到 tombstone 时会保留本机记录：无本机更改时停止同步，有未同步更改时要求选择接受删除或用本机记录重建备份。当前应用没有删除 Supabase 认证账号的功能，账号删除需联系部署者。

云端建议

只有在部署者配置云端建议服务、你主动点击并明确同意后，生成建议所需的近期状态、训练和有限长度备注才会发送到服务器并转交给配置的 AI 服务提供方。记录 ID、更新时间、习惯对象和完整动作库不会随建议请求发送。你可以在帮助页撤回授权；未配置或未同意时，应用使用本地规则生成建议。请不要在记录或备注中填写身份证号、联系方式等不必要的敏感信息。

安全与技术数据

服务器会在内存中临时使用请求来源网络地址和用户 ID 进行频率限制，以降低接口滥用风险；应用不会把网络地址写入用户记录或备份。部署环境、Supabase、网络服务或 AI 服务提供方可能按各自政策处理必要的技术日志。

保存期限与用户控制

本地数据保留到你清空站点数据、在应用内删除、卸载相关浏览器数据或设备存储被清理为止。已开启云备份时，Supabase 中的快照保留到你删除云端备份或部署者删除相应数据。删除云端备份后，快照内容被删除，但用户关联、revision、更新时间和 tombstone 会继续保留，以便其他设备识别删除；当前版本没有自动清理期限。即使使用云备份，也应保留自行导出的 JSON 备份。

未成年人

未成年人应在监护人知情和指导下使用本应用，尤其是在记录健康状态或依据建议安排训练时。

政策更新与联系

功能或数据处理方式发生变化时，本政策会更新生效日期和相关说明。隐私问题请通过你获取本应用地址时由部署与提供者给出的联系渠道反馈。

关怀摘要与主动分享

关怀摘要在当前设备上由汇总数据生成。默认不包含风险提醒，也不会包含姓名、备注原文、动作明细、记录 ID 或完整历史。只有你主动选择内容并调用系统分享或复制后，摘要才会离开应用；接收方和所用分享服务对已发送内容的后续处理不受本应用控制，请在发送前核对预览。

训练协作简报

训练协作简报在当前设备上生成，用于与教练确认训练目标、环境、计划节奏、计划兑现和执行概览。你可在分享前选择计划、兑现和执行三类信息。简报不会包含健康状态、疼痛、睡眠、备注原文、动作明细、重量、次数、具体日期或完整历史；只有你主动分享或复制后，所选汇总信息才会离开应用。

个人进展报告

个人进展报告仅在当前设备根据最近阶段的训练次数、完成组数、状态覆盖、睡眠、疼痛和计划节奏生成。它不会保存新的个人资料，也不会自动上传或分享。导出的报告不包含备注原文、动作名称、重量、次数、具体训练日期、记录 ID 或完整历史；只有你主动导出或复制后，文本才会离开应用。

Pro 长期报告

部署者启用权益服务后，服务器验证的 Pro 用户可在当前设备生成 90 天或年度纵向报告。服务器只返回权益状态；长期报告计算不会因此上传日常状态、训练历史或备注。报告只使用训练次数、完成组数、状态覆盖、活跃周/月、连续训练周、睡眠和疼痛汇总，不输出备注、动作名称、重量、次数、具体训练日期、记录 ID 或完整历史。退出、权益降级或权益服务失败会隐藏报告内容，但不会删除本机记录。

周目标校准

周目标校准只在当前设备读取最近四个已经结束自然周的训练次数和有限恢复汇总，用于判断现有每周目标是否可持续。当前未结束周和没有任何记录的周不会被视为漏练；系统不会自动提高或修改目标，只有你主动采用建议时才会更新本地偏好。导出内容只包含校准结论，不包含具体训练日期或单日健康记录。

支持约定与回访

你可分别建立最多 6 位支持伙伴。每位约定只保存支持对象类型、关怀频率、支持方式、沟通边界、下一日期及最多 12 次日期与 1 至 5 的支持感评分；不要求姓名或联系方式，不记录聊天内容或对方信息。它们随本地数据和 JSON 备份保存；只有你主动分享邀请时，被选伙伴的结构化约定才会离开应用。若该伙伴选择“提醒我完成计划”且你设置了计划训练日，邀请会包含星期安排；邀请不会附带健康、训练明细或回访评分。
