# 训练现场与本地 Beta 手机手工测试

适用版本：1.24.0。建议在 Chrome 或 Edge DevTools 的 320、375、390、430px 视口各执行一次；320 和 390px 完整执行，375 和 430px 可复查布局与触控目标。

## 准备

1. 打开 `/app/`，在浏览器站点数据中清除 WhatToDrill 的现有数据后刷新。
2. 确认页面无横向滚动，主按钮高度不小于 44px。
3. 保持 DevTools Console 打开；全流程不得出现未捕获错误。

## 首次训练

1. 点击“选择条件并开始”。确认“居家无器械”既有选中视觉，也是真实 checked radio，可直接继续。
2. 用 Tab 聚焦条件 radio，按左右方向键切换；刷新后重新打开，默认或已保存选择必须与视觉一致。
3. 用屏幕阅读器检查“在哪里练”以 fieldset/legend 作为组名，各选项能读出选中状态。
4. 依次选择无器械、哑铃、固定器械、自由重量，确认生成的首次计划与环境匹配。

## 六种记录类型

1. `weighted_reps`：显示次数和重量。
2. `bodyweight_reps`：显示次数，不显示重量快捷键。
3. `assisted_or_added_weight_reps`：显示“辅助/加重”选择；辅助量与加重量语义清楚。
4. `duration_seconds`：显示秒，快捷调整以秒为单位。
5. `duration_minutes`：显示分钟，快捷调整以分钟为单位。
6. `completion_only`：只显示完成操作，不显示数字输入。
7. 导入含旧自定义动作和旧训练草稿的备份，确认可继续训练；重新导出后仍有兼容的 `metric` 和规范 `recordType`。

## 休息与误触保护

1. 完成一组进入休息。确认只显示下一组预览，没有“完成这组”或“跳过这组”输入操作；唯一主操作是“立即开始下一组”。
2. 分别测试暂停、继续、`+30 秒` 和跳过休息；完整训练计划始终可展开查看。
3. 休息中刷新，确认倒计时与暂停状态恢复；让休息自然结束后刷新，确认下一组输入自动激活。
4. 点击“立即开始下一组”，确认输入与完成按钮出现并获得清楚的操作层级。
5. 完成一组后点击“撤销上一操作”；跳过一组后也执行撤销。两种状态均应恢复为待完成，重复点击完成或跳过不得重复推进。

## 数字键盘与视口

1. 在 320 和 390px 聚焦次数、重量、秒和分钟输入，唤起手机数字键盘。
2. 确认当前输入、单位和完成按钮仍在可视区域；必要时页面可自动滚动，但不得出现横向滚动。
3. 检查休息卡与当前动作：休息中不得同时出现两个竞争主按钮。
4. 在 320、375、390、430px 检查所有可见训练按钮，触控高度均应至少 44px。

## 本地 Beta 记录

1. 完成首次配置、开始训练、完成首组、保存训练、修改并接受下一计划，再开始和完成第二次训练；提交一次推荐反馈。
2. 打开“帮助与版本说明”中的折叠“本地 Beta 记录”。确认文字明确说明它不是在线用户分析，不上传健康内容，也不进入普通或云备份。
3. 查看最近事件；不得出现备注、实际重量、疼痛原文、邮箱或身份令牌。
4. 点击“导出本地 Beta 记录”，确认文件名为 `what-to-drill-local-beta-YYYY-MM-DD.json`，汇总包含首训、下一计划、第二次训练和反馈分布。
5. 点击一次“清除本地 Beta 记录”，确认只进入待确认状态；第二次点击后事件清空，但训练与设置不变。
6. 重新产生一条事件，再执行普通“清空本地数据”。确认训练与设置清空，Beta 记录保留且提示了独立清除入口。

## 通过标准

- 320、375、390、430px 均无横向滚动，主要按钮不小于 44px。
- 首次 radio 的视觉、DOM、键盘和屏幕阅读器状态一致。
- 休息预览不可误完成；开始下一组或倒计时结束后才激活输入。
- 完成、跳过均可撤销，重复操作不产生不可逆的额外推进。
- 本地 Beta 数据可查看、单独导出和清除，且始终与普通备份、导入和云同步隔离。
